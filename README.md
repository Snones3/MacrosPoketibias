# 🧩 Macros Poketibias

Macros desenvolvidos para auxiliar jogadores de **Poketibia**, focados em automação de ações repetitivas para melhorar a experiência de jogo.

> ⚠️ **Aviso importante**: use por sua conta e risco. O uso de macros pode violar regras de servidores.  

---

## 📥 Download

Os executáveis estão disponíveis na aba **Releases** do GitHub.

👉 Acesse:  
https://github.com/Snones3/MacrosPoketibias/releases

Sempre baixe a **versão mais recente**.

---

## ⚙️ Requisitos

- Windows 10 ou superior
- Executar como **Administrador** (recomendado)
- Teclado em layout **ABNT2** (se aplicável)

---

## ▶️ Como usar

1. Baixe o arquivo `.exe` pela aba **Releases**
2. Execute o programa
3. Configure as teclas ou opções disponíveis
4. Inicie o macro dentro do jogo

---

## 🛡️ Aviso sobre antivírus (IMPORTANTE)

Este programa **pode gerar falso positivo em antivírus**.

Isso acontece porque:
- O macro simula teclas/movimentos
- Executáveis de automação são frequentemente marcados como suspeitos

✅ O executável **não coleta dados**, **não envia informações** e **não contém malware**.

Caso seu antivírus bloqueie:
- Adicione o arquivo à lista de exceções
- Ou execute com antivírus temporariamente desativado
